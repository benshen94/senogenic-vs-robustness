# Superseded Poisson recovery diagnostic

The historical cutoff in this directory describes the original Poisson
recovery experiment only. It does not calibrate the active per-year Pearson
dispersion-adjusted bands, which use normal critical value 1.959964.

Original recovery draws, coverage summaries, and per-draw covariance remain
under `results/historical/fit_records/`. The old production covariance is not
required for those diagnostics and is not retained as an active alternative.
