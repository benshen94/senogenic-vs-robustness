# Extended Data Figure 1 methods

## Figure scope

Extended Data Fig. 1 asks whether broad smooth heterogeneity in the senogenic timescale can be hidden by refitting the SR model. The analysis fixes a population spread in

\[
\tau_{\rm sen}=\frac{\beta}{\eta}
\]

and then refits the median SR parameters and country-specific robustness parameters over wide bounds. The figure supports the claim that imposed senogenic-timescale heterogeneity worsens old-age mortality fits and introduces mortality curvature that is not rescued by broad compensatory refitting.

## Model or statistic

Individual senogenic-timescale spread is imposed as

\[
\eta_i=\eta_0 e^{-v_i/2},\qquad
\beta_i=\beta_0 e^{v_i/2},\qquad
v_i\sim N(0,\sigma_v^2).
\]

Thus

\[
\tau_i=\frac{\beta_i}{\eta_i}
\]

has log-spread \(\sigma_v\), while the fitted median \(\tau_0\) remains free to move.

The fixed-spread grid is

\[
\sigma_v=0,\ 0.025,\ 0.05,\ 0.075,\ 0.10,\ 0.13,\ 0.16,\ 0.20,\ 0.25.
\]

For each fixed spread, the all-CV stress-grid script allows the following fitted quantities to move:

\[
\eta,\quad \tau_{\rm sen},\quad \kappa,\quad \epsilon,\quad X_c^{\rm SWE},\quad X_c^{\rm USA},
\]

plus Sweden and USA \(X_c\) heterogeneity. The external Makeham-like term \(h_{\rm ext}\) remains fixed from the HMD/GGM preprocessing.

Panel A plots the best evaluated fit objective for the zero-spread baseline/free-spread row and for each positive fixed-spread profile. The dashed horizontal line is the best evaluated baseline/free-spread Sweden-oriented score.

Panel B plots Sweden 2019 HMD mortality, the baseline Sweden SR fit, and selected best wide-refit mortality curves labelled 2.5%, 5%, 10%, and 15% imposed \(\tau_{\rm sen}\) heterogeneity. The 15% curve uses the nearest available stress-grid point, \(\mathrm{CV}(\tau)\approx0.161\).

## Fitting workflow

The canonical fitting scripts are in `analysis/model_fits/tau_wide_refit_profile/`.

The final profile was generated by:

```bash
python3 analysis/model_fits/tau_wide_refit_profile/run_tau_stress_grid_refit.py
```

The stress grid screened structured, archive, source-data, targeted-stress, carryover, and random starts. It then used differential evolution followed by local coordinate refinement. The current metadata are saved in `results/cache/simulations/tau_wide_refit_profile/metadata.json`.

The targeted forced-10% search was generated by:

```bash
python3 analysis/model_fits/tau_wide_refit_profile/run_tau_cv010_stress_refit.py
```

Those candidates are saved in `results/tau_wide_refit_profile/tau_cv010_stress_refit_candidates.csv` and were used as priority starts in the all-CV stress grid.

The final best-per-CV table is `results/tau_wide_refit_profile/tau_wide_refit_profile_candidates.csv`. The full refined-candidate table is `results/tau_wide_refit_profile/tau_wide_refit_profile_all_candidates.csv`.

## Uncertainty and bands

The orange band in panel B is a fit-local endpoint envelope for the baseline Sweden fit. It is the pointwise min-max across the central baseline and one-at-a-time 95% CI endpoint perturbations of \(\eta\), \(\beta\), \(\epsilon\), and Sweden \(X_c\). Sweden \(X_c\) heterogeneity is held at the archived fitted value.

The baseline curve and endpoint simulations use \(n=1000000\) and \(\Delta t=0.025\). The selected forced-heterogeneity panel-B curves use \(n=1000000\) and \(\Delta t=0.1\).

## Known caveats

- The full stress-grid refit is stochastic and computationally expensive. The public repo includes the saved candidate tables and high-\(n\) curves used for the manuscript figure.
- The fit profile is a numerical stress test, not a mathematical proof of global optimality.
- The manuscript-safe interpretation is that late-life data constrain the favorable tail of \(\tau_{\rm sen}\), not that every possible non-smooth or truncated senogenic heterogeneity distribution is excluded.
